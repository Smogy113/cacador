# v2 jogável — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Primeiro ciclo completo de jogo: aceitar recompensa → esconderijo → tiroteio de revólver com mira livre → render/matar → levar ao xerife → receber dinheiro, com bússola.

**Architecture:** Toda a regra (arma, acerto, vida, IA do bando, temperamentos, caçada/recompensa, zona de exclusão dos moradores) é lógica pura em `src/core/` com testes doctest. `src/game/` só lê mouse/teclado, desenha (poses novas, revólver, efeitos, HUD) e liga as peças. Bandidos são "combatentes" próprios, fora da `Populacao`.

**Tech Stack:** C++17, raylib 5.5, GLSL 330/100, doctest. Arquivos novos em `src/core/*.cpp` e `tests/*.cpp` entram sozinhos no build (glob no CMake).

**Spec:** `docs/superpowers/specs/2026-11-21-v2-jogavel-design.md`

## Global Constraints
- Sem arquivos de modelo nem som; tudo gerado por código.
- Benchmark Baixo ≤ 350 mil triângulos e ≤ 350 chamadas, inclusive na cena de tiroteio.
- Web (GLSL 100) compila e roda no Baixo.
- Moradores mantêm a rotina; a única mudança na `Populacao` é a zona de exclusão (raio 80 m).
- Valores de partida (spec): 6 balas; recarga 2 s; cadência 0,35 s; dano corpo 34, cabeça mata; vida do jogador 100, tiro de bandido 18, regenera após 5 s a 12/s; rendição/fuga abaixo de 35% da vida; temperamentos 40/35/25%; capangas 2 (recompensa < 100) ou 3; bando criado a 150 m, removido a 400 m sem luta; visão 35 m, audição 80 m; reação 0,6 s; ≤ 2 atirando; combate a 10–25 m; amarrar a 2 m segurando E 1,5 s; levar a ≤ 8 m; xerife a 4 m; fujão se rende a 4 m; capangas somem a 120 m.
- Textos de tela sem acento (fonte padrão), via `semAcentos`.

## Review Focus
1. Bandido nascendo dentro de caixa de colisão ou na água → recompensa impossível. Teste em Task 4: esconderijo e posições do bando livres de colisão, em terra, dentro do jogável, para todos os lugares do mapa padrão.
2. Jogador morre com o alvo amarrado/na garupa → o alvo não pode sumir nem ficar preso. Teste em Task 4: `morrerJogador` com alvo Amarrado deixa o alvo Amarrado no esconderijo e a caçada volta a `Combate`/coleta, nunca `Nenhuma`.
3. Aceitar outra recompensa no meio do tiroteio → bando antigo some, moradores voltam. Teste em Task 4: trocar a ativa limpa bando e zona de exclusão.
4. Tiro saindo de dentro da parede (câmera atrás de muro, mira do outro lado) → não pode acertar através. Teste em Task 1: origem do raio é o cano; se o cano→ponto mirado cruza uma caixa, o tiro para nela.
5. Fujão preso num canto/terreno íngreme e nunca alcançável → teste em Task 3: fujão nunca é mais rápido que `VEL_CORRER`, e a 4 m do jogador ou montado a 4 m ele se rende.

```cpp
struct Revolver {
    int balas = 6; float recarga = 0, espera = 0;      // recarga > 0: recarregando; espera: cadencia
    bool podeAtirar() const;                            // balas > 0 && recarga <= 0 && espera <= 0
    void atirar();                                      // balas--, espera = 0.35
    void recarregar();                                  // se balas < 6 e nao recarregando: recarga = 2.0
    void atualizar(float dt);                           // ao terminar a recarga: balas = 6
};
struct Vida {
    float atual = 100, max = 100, semDano = 0;          // semDano: segundos desde o ultimo dano
    void dano(float v); bool morto() const; float fracao() const;
    void atualizar(float dt, bool regenera);            // regenera 12/s apos 5 s sem dano

constexpr float DANO_CORPO = 34.f, DANO_BANDIDO = 18.f, LIMIAR_RENDER = 0.35f;
enum class Parte { Nada, Corpo, Cabeca };
struct Alvo { Vec3f pes; float altura = 1.8f; };       // cilindro do corpo r=0.28 ate 0.82*altura; cabeca esfera r=0.13 em 0.92*altura
struct Acerto { int indice = -1; Parte parte = Parte::Nada; float dist = 0; Vec3f ponto; };
// Raio de 'origem' em 'dir' (normalizada) ate 'alcance'; para no terreno e nas caixas; retorna o alvo mais proximo
Acerto lancarTiro(Vec3f origem, Vec3f dir, float alcance, const std::vector<Alvo>& alvos, const Terreno& t, const MundoColisao& col);
// Desvio da mira (radianos): base + distancia + velocidade do alvo; 'mirando' reduz
float espalhamento(bool mirando, float velAtirador);
```

### Task 3: Bando e IA (`core/bando`)

**Files:** Create `src/core/bando.h`, `src/core/bando.cpp`, `tests/test_bando.cpp`

**Interfaces — Consumes:** Task 1 (`Revolver`, `Vida`, `Alvo`, `lancarTiro`, `espalhamento`, `DANO_BANDIDO`, `LIMIAR_RENDER`), Task 2 (`Temperamento`).
**Produces:**
```cpp
enum class EstadoBandido { Vigiando, Alerta, Combate, Fugindo, Rendido, Amarrado, Morto, Sumiu };
struct Bandido {
    Corpo corpo; Vida vida; Revolver arma; EstadoBandido estado = EstadoBandido::Vigiando;
    bool chefe = false; Temperamento temperamento = Temperamento::Teimoso;
    float reacao = 0.6f, tranco = 0, tempoMorto = 0; Vec3f cobertura; uint32_t semente;
};
struct EventosBando { int tirosNoJogador = 0; std::vector<Vec3f> claroes; bool chefeRendeu = false, chefeMorreu = false; };
class Bando {
public:
    Bando() = default;
    Bando(Vec3f esconderijo, Temperamento t, int capangas, uint32_t semente, const Terreno&, const MundoColisao&);
    // jogadorMontado: chegar a 4 m montado tambem rende o fujao
    EventosBando atualizar(float dt, Vec3f jogador, float velJogador, bool jogadorMontado, bool tiroOuvido,
                           const Terreno&, const MundoColisao&);
    // o jogador atirou e acertou: aplica dano/tranco/estado; retorna true se matou
    bool levarTiro(int indice, Parte parte);
    std::vector<Alvo> alvos() const;                 // so quem pode levar tiro (nao Morto/Sumiu)
    std::vector<Bandido>& bandidos(); const std::vector<Bandido>& bandidos() const;
    Bandido* chefe();
    void curarTodos();                               // vivos voltam a vida cheia e Vigiando (morte do jogador)
    bool vazio() const;
};
```
Regras (valores da spec): Vigiando → Alerta se jogador ≤ 35 m com `raioLivre` olho-a-olho, ou `tiroOuvido` a ≤ 80 m; Alerta conta `reacao` e vira Combate; Combate escolhe cobertura (ponto livre atrás da caixa de colisão mais próxima a ≤ 15 m, do lado oposto ao jogador; sem caixa: manter 10–25 m andando de lado) e atira em rajadas de 1–3 tiros com `espalhamento` + 0,02 rad/m de distância + 0,015 × velJogador; acerto no jogador é sorteado pela abertura angular do corpo dele (cilindro r 0.28) contra o desvio; ≤ 2 bandidos atirando por vez. Chefe abaixo de 35%: Covarde → Rendido; Fujao → Fugindo (velocidade 3,5 m/s, sempre < `VEL_CORRER`) e Rendido quando jogador ≤ 4 m (a pé ou montado); Teimoso continua. Rendido que leva tiro morre. Chefe Rendido/Morto → capangas vivos Fugindo e `Sumiu` a 120 m. `Amarrado` só é posto por fora (Task 4).
