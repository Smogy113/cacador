# Casas realistas e ocas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um gerador por gramática (core, testável) produz todas as casas/prédios ocos e entráveis, nos estilos medieval e faroeste, com porta que abre (E), interior mais escuro e câmera que se aproxima.

**Architecture:** `core/predio` devolve uma planta (peças, colisão girada, porta, janelas, interior, pisos, entrada) em coordenadas do lote; `render/props` converte em malha (detalhe perto, casca longe) e registra formas/colisão; o jogo controla portas e câmera; os shaders recebem os interiores próximos para escurecer o ambiente.

**Tech Stack:** C++17, raylib 5.5, GLSL 330/100, doctest.

**Spec:** `docs/superpowers/specs/2026-11-22-casas-design.md`

## Global Constraints
- Porta ≥ 1,0 × 2,1 m; pé-direito ≥ 2,6 m; interior livre ≥ 2,5 m de lado; paredes ~0,2 m (madeira) / ~0,4 m (pedra); piso a 0,35 m do chão mais alto do lote, degrau na porta.
- Medieval: cidade e vilarejos (casas, taverna, xerife, cadeia, capela). Faroeste: casa e celeiro da fazenda, barracão novo na mina. Estábulo segue aberto.
- Só o térreo acessível; porta começa fechada; E a < 1,5 m abre/fecha; inimigos/cavalos/moradores não entram.
- Interior: ambiente ~25% ao fundo, mais claro perto da porta/janelas abertas; nunca preto.
- Detalhe ≤ ~6 mil triângulos por casa; casca simples além de 90 m; Médio/Alto no máximo +10% de triângulos/chamadas no vilarejo e na cidade; Baixo ≤ 350 mil / 350 no benchmark.
- Luz traçada das paredes continua (painéis = formas `parede`); limite de formas por face 32 → 64.
- Versão 0.20.0 ao final.

## Review Focus
1. Entrar/sair rente ao batente, girar dentro de casa, encostar nas quinas giradas → nunca preso nem atravessa. Task 1 (testes de colisão girada) + Task 4 (teste "caminho da porta ao centro").
2. Câmera dentro de cômodo pequeno → não entra na parede nem mostra o lado de fora pelo telhado. Task 5: capturas dentro.
3. Porta fechando com o caçador no vão → não prende (fecha só se o vão estiver livre). Task 4: teste.
4. Lote em terreno inclinado → piso, degrau e alicerce sem buraco nem casa flutuando. Task 3: captura em encosta.
5. Noite dentro de casa com lanterna → visível, não preto; janela acesa por dentro. Task 5: captura.

### Task 2: Gerador de prédios por gramática (core)
**Files:** `src/core/predio.{h,cpp}`, `tests/test_predio.cpp`
**Produces:**
```cpp
enum class Estilo { Medieval, Faroeste };
enum class TipoPredio { Casa, Taverna, Xerife, Cadeia, Capela, Celeiro, Barracao };
enum class MatPeca { Reboco, Madeira, MadeiraEsc, Pedra, Telhado, Tabuinha, Palha, Ardosia, Vidro, Ferro, Escuro };
struct PecaPredio { bool prisma = false; Vec3f centro, tam; float rotY = 0; MatPeca mat; Rgb cor; bool forma = false; bool detalhe = false; bool dentro = false; };
struct PortaPredio { Vec3f dobradica; float largura, altura, rotFechada; float sentido; /* +1/-1 */ };
struct Planta {
    std::vector<PecaPredio> pecas;             // coordenadas do lote (frente em +z, chao em y = 0)
    std::vector<CaixaGirada> paredes;          // colisao (local), vao da porta livre
    PortaPredio porta;
    std::vector<JanelaLuz> janelas;
    Vec3f interiorCentro, interiorMeia;        // volume interior (local, rot 0)
    float piso;                                // altura do piso
    Vec3f entrada;                             // ponto na frente da porta (moradores, quadros)
};
struct Lote { float largura, profundidade; int andares; Estilo estilo; TipoPredio tipo; uint32_t semente; Rgb corParede, corTelhado; };
Planta gerarPredio(const Lote& l);
```
- [ ] Testes (para 300 sementes × estilos × tipos): `predio: porta no terreo e para fora`, `predio: vao da porta livre de colisao (>= 1,0 x 2,1)`, `predio: janelas sem sobreposicao entre si e com a porta`, `predio: interior livre >= 2,6 de altura e 2,5 de lado`, `predio: caminho da entrada ao centro sem colisao` (círculo r 0,35 andando reto pela porta), `predio: pecas dentro do lote (+ beiral/varanda)`, `predio: variedade` (20 sementes → ≥ 12 combinações distintas de vãos/telhado), `predio: orcamento` (peças detalhadas ≤ 600 caixas, ~6 mil triângulos).
- [ ] RED → implementar gramática (volume, andares, vãos, peças por estilo; anexo "L" nas medievais grandes; varanda e fachada falsa no faroeste) → GREEN → commit `feat: gerador de predios por gramatica`.
